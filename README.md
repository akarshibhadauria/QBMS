# 📚 Question Bank Management System

A web-based Question Bank Management System designed to simplify question management and randomized question paper generation for educational institutions.

## 🚀 Live Demo

https://qbms-iota.vercel.app/

## ✨ Features

- 🔐 User Registration and Login
- 👥 Role-based access
- 📚 Question Bank Management
- ➕ Add and Manage Questions
- 🎲 Randomized Question Paper Generation
- 📝 Paper Management
- ✅ Question/Paper Approval
- 📊 Analytics Dashboard
- 🔔 Notifications
- 📜 Question History
